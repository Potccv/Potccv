# rule-check 执行与维护入口

`rule-check` 是本源码仓库随源码发布的独立 Python 只读工具，不属于主仓库的构建步骤。本文件维护工具特有的常驻边界；具体使用与开发正文按任务读取。

## 工具边界

- 工具必须能在声明的 Python 依赖就绪后单独运行，不导入本仓库的其他 Python 模块，不依赖工作区中其他工具、残留产物或默认目录。
- 保持[只读边界与路径安全](usage.md#只读边界与路径安全)：只读取显式目标和必要 Git 元数据，普通运行只向标准输出报告，不修改目标、不生成文件、不请求网络，不读取真实个人配置、凭据或个人 `profile` 内容。
- 解释器、工作目录、输入路径和输出重定向由调用者传入，不在源码中硬编码本机路径。源码仓库版本中不包含 `venv`、解释器缓存或个人 profile 数据。
- requirements.txt 中的精确依赖只在依赖变更任务中调整；无关修改不得升级、替换或补充依赖。
