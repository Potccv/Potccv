# Potccv

Potccv 整理了 AI 协作时会用到的开发、Git、文档和个人配置资料。本页面向希望了解项目内容的读者，完整规范从 [AGENTS.md](AGENTS.md) 进入。

仓库主体为 Markdown 规则文档和 JSON 配置示例。文档分工见[维护本项目](AGENTS.md#维护本项目)。

## 文档导航

| 入口 | 内容 |
|---|---|
| [AGENTS.md](AGENTS.md) | 面向 agent 的任务入口、执行约束和维护要求 |
| [通用约定](rules/README.md) | 范围判定、共同维护要求及分类导航 |
| [个人配置](profile/README.md) | 配置模板及其使用规范的导读 |
| [规则校验工具](tools/rule-check/README.md) | 只读检查源码仓库规则和工作区事项 |
| [Git 提交验证工具](tools/git-submit/README.md) | 签名提交、推送及远端分支和 GitHub 签名验证 |
