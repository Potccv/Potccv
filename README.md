# Potccv

Potccv 整理了 AI 协作时会用到的开发、Git、文档和个人配置资料。本页面向希望了解项目内容的读者，完整规范从 [AGENTS.md](AGENTS.md) 进入。

根目录 AGENTS.md 指向一级目录入口，各级 AGENTS.md 按职责继续导航到下级入口或主题文档。Git、事项管理和测试等内容在各自目录内分文件维护；README 面向人介绍和导航，具体执行规则保留唯一维护位置。

## 文档导航

| 入口 | 内容 |
|---|---|
| [AGENTS.md](AGENTS.md) | 面向 agent 的任务入口、执行约束和维护要求 |
| [通用约定](rules/README.md) | 范围判定、共同维护要求及分类导航 |
| [源码仓库规则](rules/repo/README.md) | 编程、正式文档、测试源码、发布交付与 Git 操作 |
| [工作区规则](rules/workspace/README.md) | 布局、资料、事项、测试执行、辅助工具和协作 |
| [个人配置](profile/README.md) | 配置模板及其使用规范的导读 |
| [仓库工具入口](tools/AGENTS.md) | 随仓库发布的独立工具及其维护入口 |
| [规则校验工具](tools/rule-check/README.md) | 只读检查源码仓库规则和工作区事项 |
