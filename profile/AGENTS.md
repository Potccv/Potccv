# AGENTS.md — 个人配置入口

本文件是个人配置的执行入口，补充[根目录执行要求](../AGENTS.md)。

## 按任务读取

- 任务需要真实身份、环境、连接、签名、认证、提交偏好、子智能体参数或项目定位参数时，阅读[选择配置](configuration.md#选择配置)、所需的[字段职责](fields.md#字段职责)和[凭据与发布](maintenance.md#凭据与发布)，仅提取本次需要的字段。
- 建立或调整个人配置时，再阅读[建立配置](configuration.md#建立配置)及相关字段说明；维护公开文档、空白示例或忽略规则时，阅读[维护配置](maintenance.md#维护配置)及与变更相关的章节，无须读取真实个人配置或凭据。
