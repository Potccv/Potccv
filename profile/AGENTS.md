# AGENTS.md — 个人配置文档与示例

本文件规定个人配置的选取、使用和维护方式，补充[根目录执行要求](../AGENTS.md)。

## 按任务读取

- 任务需要真实身份、环境、连接、签名、认证、提交偏好或项目定位参数时，阅读[选择配置](#选择配置)、所需的[字段职责](#字段职责)和[凭据与发布](#凭据与发布)，仅提取本次需要的字段。
- 建立或调整个人配置时，再阅读[建立配置](#建立配置)及相关字段说明；维护公开文档、空白示例或忽略规则时，阅读[维护配置](#维护配置)及与变更相关的章节，无须读取真实个人配置或凭据。

## 选择配置

按以下顺序选择一份 JSON 配置，不自动合并多份配置：

1. 已设置环境变量 `POTCCV_PROFILE`：读取它指定的绝对路径。文件不存在或格式错误时先报告问题，不静默改读其他配置。
2. 未设置环境变量且仓库内存在 `profile/local.json`：读取该文件。
3. 否则读取用户目录下的 `~/.potccv/profile.json`。Windows 上 `~` 对应当前用户目录。
4. 都不存在时，说明个人配置尚未建立；不把示例中的空值当成实际环境或授权。

本仓库不提供自动加载程序，使用本资料的 agent 或工具按此约定查找。

## 建立配置

已有配置时直接编辑现有文件，不用空模板覆盖。首次建立仓库内配置时，可在本项目根目录执行以下 PowerShell 命令；已有同名文件会保留：

```powershell
if (-not (Test-Path -LiteralPath './profile/local.json')) {
    Copy-Item -LiteralPath './profile/example.json' -Destination './profile/local.json'
}
```

随后按需填写配置。配置中的文件路径使用绝对路径或 `~` 开头的用户目录路径。

仓库外配置可由示例复制到[选择配置](#选择配置)约定的用户目录位置，也可以放在其他位置并将 `POTCCV_PROFILE` 指向该文件的绝对路径。

## 字段职责

字段结构以[配置示例](example.json)为准，含义如下：

| 字段 | 内容 |
|---|---|
| `schema_version` | 配置结构版本，当前值见[配置示例](example.json) |
| `identity` | 个人显示名称 |
| `paths` | 工作区根目录与 SSH 密钥、签名公钥等本机路径 |
| `credentials.file` | 已有凭据文件的位置 |
| `credentials.values` | 选择直接在个人配置中保存的凭据；与 `credentials.file` 二选一，不混用 |
| `preferences` | 提交偏好、默认测试主机别名、消息图片发送方式等个人设置 |
| `preferences.auto_commit_and_push` | 修改完成后是否自动提交并推送至 GitHub；布尔值，默认 `false`，缺失时按 `false` 处理，执行规则见[版本与授权](../rules/git/AGENTS.md#版本与授权) |
| `hosts`、`devices`、`services` | 设备地址、服务入口、连接方式及设备允许操作的范围，可附最后核验日期 |
| `contacts` | 消息任务需要的联系人标识 |
| `project_locations` | 项目工作区与资料目录的定位路径，仅作入口索引，不承载完整项目资料；资料位置遵循[资料存放位置](../rules/docs/AGENTS.md#资料存放位置) |

## 凭据与发布

- 只在任务需要时读取对应凭据字段。
- 真实个人数据保存在个人配置或其引用的外部凭据文件中，不写入公开文档。个人配置保持未跟踪，不通过强制添加纳入 Git。
- 公开文件白名单和本地文件忽略模式以[根目录 .gitignore](../.gitignore)为准。
- 仓库内其他位置的个人配置可使用 `*.local.json` 命名；使用其他文件名时，检查是否被忽略规则覆盖，必要时补充规则。
- `.gitignore` 只影响未跟踪文件，已跟踪的真实配置不会因此退出版本控制。个人配置与凭据在换设备时单独迁移。

## 维护配置

- [example.json](example.json) 只保留结构、空的个人数据字段及通用默认值，`schema_version` 等结构元数据保留有效值。
- 修改字段时同步更新示例和本文件的[字段职责](#字段职责)。
- 新增公开文件时，在[根目录 .gitignore](../.gitignore) 中添加精确例外，保留其他配置文件和子目录的忽略规则。
- 交付前确认示例是有效 JSON；忽略规则变更后，核对公开文件可被跟踪，`local.json`、其他个人配置和子目录仍被忽略。
