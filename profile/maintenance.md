# 个人配置维护

## 凭据与发布

- 连接设备优先使用 SSH 密钥，密码仅作回退。
- 只在任务需要时读取对应凭据字段。
- 凭据仅按需用于已授权的连接，避免真实凭据值进入参数转储、普通日志、异常输出、对话或交付；诊断只展示必要的字段名或脱敏内容，不打印整份私有配置。
- 真实个人数据保存在个人配置或其引用的外部凭据文件中，不写入公开文档。个人配置保持未跟踪，不通过强制添加纳入 Git。
- 公开文件白名单和本地文件忽略模式以[根目录 .gitignore](../.gitignore)为准。
- 仓库内其他位置的个人配置可使用 `*.local.json` 命名；使用其他文件名时，检查是否被忽略规则覆盖，必要时补充规则。
- `.gitignore` 只影响未跟踪文件，已跟踪的真实配置不会因此退出版本控制。个人配置与凭据在换设备时单独迁移。

## 维护配置

- [example.json](example.json) 只保留结构、空的个人数据字段及通用默认值，`schema_version` 等结构元数据保留有效值。
- 修改字段时同步更新示例和[字段职责](fields.md#字段职责)。
- 新增公开文件时，在[根目录 .gitignore](../.gitignore) 中添加精确例外，保留其他配置文件和子目录的忽略规则。
- 交付前确认示例是有效 JSON；忽略规则变更后，核对公开文件可被跟踪，`local.json`、其他个人配置和子目录仍被忽略。
