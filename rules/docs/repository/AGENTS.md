# AGENTS.md — 源码仓库文档

先按[文档位置与适用范围](../AGENTS.md#文档位置与适用范围)确认归属。本文件适用于 `<源码仓库>/docs/`，以及源码仓库内的 README.md、CONTRIBUTING.md、模块就近说明和相关 AGENTS.md；共同写作与验证要求见[文档与资料](../AGENTS.md)。

## 文档职责

以下采用 DSH 的通用分层方式，按内容和目录职责选择文档，不要求每个目录同时创建 AGENTS.md 与 README.md。所属源码项目已有约定时遵循其约定；Potccv 的 AGENTS.md 与 README.md 分工优先按[维护本项目](../../../AGENTS.md#维护本项目)执行。

| 文件 | 职责 |
|---|---|
| 根目录 AGENTS.md | 每次任务需要的常驻要求；条目简短自洽，链接到详细说明，不展开情境操作步骤 |
| 目录级 AGENTS.md | 该子树特有的执行或维护要求，不复述上层已有规则；有此类要求时再建立 |
| README.md | 所属项目、目录或模块的介绍、用途、使用方式、配置语义、限制及导航 |
| 架构与参考文档 | 分别维护整体组成关系与所属主题的详细定义、语义和接口，不越级展开子模块细节 |
| 教程、操作指南与开发文档 | 按前置条件和步骤说明如何完成任务，包含所需验证；简短内容可在所属文档中单设章节 |
| 决策与事故记录 | 保存决策背景、权衡或事件证据，避免在常驻指令和使用说明中叙述历史 |
| JSON 配置、忽略规则等机器可读文件 | 保存实际字段结构、格式版本、匹配模式等数据；文档引用这些文件，不另行维护一份清单 |

## 正式说明与维护范围

- 项目概览、架构、接口、构建与使用方法、可共享开发规范在所属源码仓库内维护，形成读懂和使用项目所需的自足说明。
- 正式说明可以声明外部依赖、链接公开资料，并给出参数化的外部输入和可配置输出示例；不能要求读者读取本机私有说明或某次任务报告才能理解项目的接口、构建或使用方法。
- 公共接口、配置语义和使用示例应反映源码项目当前有效的公开契约；有变化时，在对应源码项目任务范围内同步维护相关正式说明。
- 同一事实只保留一个维护来源，按[文档职责](#文档职责)归入对应文档或机器可读文件，其他位置通过链接引用；本机操作过程、真实数据路径和任务进展归入 `<工作区>/docs/`，由其引用正式说明。
- 源码仓库内文档的组织、命名、更新和保留方式遵循所属源码项目约定；维护 `<工作区>/docs/` 不自动授权修改源码仓库的文档或文件。
- 工作区事项模板、`<工作区>/docs/tasks/待办事项/` 与 `<工作区>/docs/tasks/完成事项/`、事项文末时间记录以及本机旧文件清理规则，不自动适用于源码仓库文档。
- 不为套用工作区事项或清理规则而批量迁移、改名或删除源码仓库文件；源码项目自身的变更记录、历史资料和版本策略遵循该项目约定。
- 在对应源码项目任务范围内新增、移动或删除文档时，按该项目约定更新已有导航、相关 AGENTS.md 入口和受影响引用，并核对链接、标题锚点与示例。
