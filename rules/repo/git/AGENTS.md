# 版本、发布与提交入口

使用本资料处理版本、签名、提交或推送时，遵循本入口、[源码仓库入口](../AGENTS.md)及[根目录执行要求](../../../AGENTS.md)。维护本目录文档时，同时遵循[共同写作与核对](../../maintenance.md#共同写作与核对)。

版本、发布与提交决策阅读[版本与授权](release.md#版本与授权)及[发布整理与源码仓库发布目录](release.md#发布整理与源码仓库发布目录)；实际提交或推送时再读[提交与核验步骤](commits.md#提交与核验步骤)和[补签与推送](commits.md#补签与推送)；需要设置或修复签名时再读[签名配置](signing.md#签名配置)。
