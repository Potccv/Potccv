# demo 交付

用户要求生成 demo 时，遵循本文件及[源码仓库入口](AGENTS.md)，涉及测试源码时阅读[源码测试与验证](testing.md)，开展运行验证时阅读[工作区测试与验证](../workspace/testing/execution.md)。维护本文件时，同时遵循[共同写作与核对](../maintenance.md#共同写作与核对)。

- 用户要求生成 demo 时，默认构建整个项目，交付完整项目编译后的产物供用户测试；只有用户明确指定仅包含哪些功能时，才按其指定范围生成 demo。
- 构建方式遵循[项目构建](../workspace/build.md)。
- 产物存放遵循[工作区布局](../workspace/layout.md)。交付时说明产物路径、运行方式及实际验证结果。
