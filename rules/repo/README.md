# 源码仓库规则

本目录提供源码、正式文档、测试源码、版本发布、提交与产物交付相关规则的主题导航。执行入口见[本目录 AGENTS.md](AGENTS.md)，版本、发布与提交按[Git 入口](git/AGENTS.md)分流。

| 任务 | 规则入口 |
|---|---|
| 编写或修改源码 | [编程规范](coding.md) |
| 维护随源码发布的正式文档和约束入口 | [源码仓库文档](docs.md) |
| 编写或修改测试源码、维护测试可运行条件 | [测试源码与依赖](testing.md) |
| 版本确认、发布整理与交付（含 demo） | [版本、发布与交付](git/release.md) |
| 提交、核验、补签与推送 | [提交与推送](git/commits.md) |
| 设置或修复签名 | [签名配置](git/signing.md) |

本机开发工具、资料与产物布局、测试运行和工作区记录见[工作区规则](../workspace/README.md)；文档归属与交付说明见[范围规则](../scope.md)。
