# 源码仓库规则入口

本文件补充[根目录执行要求](../../AGENTS.md)，适用于 `<源码仓库>` 内待提交的源码、正式文档、测试源码，以及版本、提交、GitHub 发布与 demo 交付相关工作。维护本目录约束时，同时遵循[共同写作与核对](../maintenance.md#共同写作与核对)。

先确认实际源码仓库根和目标文件的完整路径，再按任务读取对应规则；所属源码项目已有约定时，同时遵循其约定。

| 任务 | 规则入口 |
|---|---|
| 编写或修改源码 | [编程规范](coding.md) |
| 维护随源码发布的正式文档和约束入口 | [源码仓库文档](docs.md) |
| 编写或修改测试源码、维护测试可运行条件 | [测试源码与依赖](testing.md) |
| 确认版本、发布、配置签名、提交与推送 | [版本、发布与提交入口](git/AGENTS.md) |
| 用户要求生成 demo | [demo 交付](demo.md) |

本机开发工具、资料与产物布局、测试运行和工作区记录的规则见[工作区入口](../workspace/AGENTS.md)；文档归属按[文档位置与适用范围](../scope.md#文档位置与适用范围)确认，交付结果按[交付说明](../scope.md#交付说明)说明。
