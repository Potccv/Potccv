# AGENTS.md — 开发协作

使用本资料开展开发协作时，遵循本文件及[根目录执行要求](../../AGENTS.md)。维护本目录文档时，同时遵循[通用约定文档的维护要求](../AGENTS.md)。

## 按任务读取

| 任务 | 执行要求 |
|---|---|
| 启动项目、准备工作区 | [工作区布局](coding/workspace/AGENTS.md) |
| 编写或修改源码、开展测试、生成 demo | [编码与测试](coding/AGENTS.md) |
| 编写文档、整理资料、记录状态 | [文档与资料](doc/AGENTS.md) |
| 连接环境、发送消息 | [环境与消息](#环境与消息) |

## 环境与消息

- 连接或发送消息需要个人环境参数时，按[个人配置](../../profile/AGENTS.md#按任务读取)选读相关要求。
- 连接设备优先使用 SSH 密钥，密码仅作回退。
- 图片尽量使用本地文件地址，避免 base64。
