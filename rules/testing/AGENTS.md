# AGENTS.md — 测试与验证

使用本资料开展开发验证、测试或清理测试临时文件时，遵循本文件及[根目录执行要求](../../AGENTS.md)。维护本目录文档时，同时遵循[通用约定文档的维护要求](../AGENTS.md)。

开展验证时阅读[开发与验证](#开发与验证)，需要测试临时文件时再读[测试临时目录](#测试临时目录)。

## 开发与验证

- 条件允许时，先在本地验证，再到获准的测试设备核验实际运行情况。
- 涉及 UI 的测试应在用户协作下完成。
- 验证结果按[状态记录](../docs/AGENTS.md#状态记录)记录。

## 测试临时目录

- 测试需要临时文件时，在[工作区布局](../workspace/AGENTS.md)约定的临时文件目录内为本次测试新建专用子目录，按 `YYYYMMDD-HHmmss-测试内容` 命名；日期时间采用创建时的本地时间，测试内容使用简短、可识别的描述，例如 `20261005-153000-接口冒烟测试`。
- 测试通过后，按[状态记录](../docs/AGENTS.md#状态记录)保存必要的验证记录，并及时删除本次测试的临时目录及其中的文件。
- 需要用户手动删除的目录统一加 `!` 前缀，便于按名称升序排列时优先显示；测试已通过的目录同时加 `-PASS` 后缀，命名为 `!原目录名-PASS`，例如 `!20261005-153000-接口冒烟测试-PASS`。已有前缀或后缀时不重复添加。
- 测试通过后的删除操作若被自动拦截，按上述方式标记目录，并告知用户测试已通过但清理未完成，提供实际目录路径，提醒用户手动删除。若重命名也被拦截，保留原名并如实报告实际路径及未能标记的情况。
