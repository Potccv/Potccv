# 工作区事项入口

本目录维护 `<工作区>/docs/tasks/` 的事项规则，补充[工作区入口](../AGENTS.md)。这些状态、时间和迁移要求不自动套用到源码仓库文档。

| 任务 | 必读主题 |
|---|---|
| 拆分、建项、领取、交接、验收、完成或取消事项 | [事项管理](management.md) |
| 创建或更新事项正文、文件名、摘要和时间 | [事项格式](format.md) |

事项处理涉及正文或状态更新时，同时遵循管理与格式要求；本机资料位置和状态记录按[工作区开发文档](../docs.md)维护。只读核对方式见[模板与只读核对](format.md#模板与只读核对)。
