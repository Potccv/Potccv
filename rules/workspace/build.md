# 项目构建

构建项目或准备发布构建时，遵循本文件及[工作区入口](AGENTS.md)。构建目录与产物位置遵循[工作区布局](layout.md)，发布产物的交付要求见[版本、发布与交付](../repo/git/release.md)。

- 默认优先增量构建，复用与当前目标、工具链和构建配置相匹配的已有构建目录及中间产物，通过项目现有构建工具判断需要重新编译和链接的内容。
- 保留仍可复用的构建目录、缓存和中间产物，不因一次构建或任务完成而默认执行 `clean`、`rebuild` 或删除构建目录。用户明确要求全量重建，或已确认项目构建要求或当前问题需要清理重建时，再按授权范围执行并说明原因。
- “构建整个项目”或交付完整发布产物表示完成所需的构建目标和交付范围，仍优先使用增量构建，不等于清理后全量重编译。
