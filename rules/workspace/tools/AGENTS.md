# AGENTS.md — 本机开发工具

本文件适用于源码仓库外的 `<工作区>/tools/<工具名>/`，遵循[根目录执行要求](../../../AGENTS.md)及[工作区布局](../AGENTS.md)。维护本目录文档时，同时遵循[文档范围与共同要求](../../AGENTS.md)。

- 仅供本机长期使用的采集或开发辅助工具放在源码仓库外，归属按[目录职责](../AGENTS.md#目录职责)确定；一次性脚本归入 `tmp/`。仓库正式维护的构建、质量检查工具遵循项目约定。
- 每个本机工具按[目录与文件组织](../AGENTS.md#目录与文件组织)独立组织，提供自己的入口、使用说明和依赖声明；所声明的依赖就绪后，能够单独构建、运行和验证，不依赖无关工具先启动、其他工具的私有目录或残留产物。
- 共享依赖显式声明版本、接口和取得方式，可复用公共库或环境；依赖冲突时隔离，不为名义上的独立复制共有实现或强制重复安装。
- 复用项目能力时通过公开接口、SDK 或可引用库，项目不反向依赖本机工具。
- 输入和输出通过参数或本机配置传入，不硬编码个人数据或历史任务路径。
- 产品构建、基础测试和正式打包不默认绑定本机工具，也不因工具复用产品模块就自动将其纳入主产品。

本机工具的实现遵循[编程基本原则](../../repo/coding/AGENTS.md#编程基本原则)和[修改范围](../../repo/coding/AGENTS.md#修改范围)，包括脚本语言选择、保护已有改动和避免无关重构；这些引用约束本机工具的实现与修改，不扩大源码仓库文件的维护范围。
