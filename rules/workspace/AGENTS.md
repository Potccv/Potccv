# AGENTS.md — 工作区布局

使用本资料启动项目、准备工作区或生成开发测试文件时，遵循本文件及[根目录执行要求](../../AGENTS.md)。维护本目录文档时，同时遵循[通用约定文档的维护要求](../AGENTS.md)。

- 使用本约束开始项目前，先在当前工作区内建立与工作区同名的子目录，作为待推送到 GitHub 的项目目录；已有同名目录时沿用。所有计划推送的内容都放入该目录，包括源码、项目文档和必要配置。
- AI 应根据项目与当前任务的实际需要，在工作区内按需建立开发与测试目录，优先沿用已有合适目录；确有对应内容需要存放时才创建，并与待推送目录同级。下表仅列出可选目录示例。

| 可选目录 | 创建条件与用途 |
|---|---|
| `tmp/` | 需要保存开发临时文件、测试临时文件或临时打包文件时 |
| `build/` | 需要保存编译、构建或交付产物时 |
| `data/` | 需要保存开发、测试或运行数据时 |
| `doc/` | 需要保存本机开发、测试或交付资料时，分类见[资料存放位置](../docs/AGENTS.md#资料存放位置) |

- 开发与测试使用或生成的临时文件、日志、数据、缓存、构建产物、tarball 和备份均须保存在当前工作区内，禁止放到系统临时目录、工作区外的同级目录或其他位置。启动相关工具前，将其临时目录、输出目录和相关缓存目录配置到工作区内；备份保留策略沿用项目自身约定。
- 涉及个人配置与凭据时，按[凭据与发布要求](../../profile/AGENTS.md#凭据与发布)单独管理。
