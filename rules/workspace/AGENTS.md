# 工作区规则入口

本目录管理本机工作区的目录、资料、事项、工具、验证运行、参考源码和任务协作，遵循[通用规则入口](../AGENTS.md)。源码仓库中的代码、正式文档、测试源码和 Git 操作从[源码仓库入口](../repo/AGENTS.md)进入。

## 常驻要求

- 所有任务的子智能体启用、参数与调度统一遵循[子智能体协作](collaboration.md)。
- 涉及源码实现时，实现复杂度与防御性逻辑同时遵循[源码编程规范](../repo/coding.md#实现边界与复杂度)；本机工作区文档不复制该正文。
- 创建文件或运行会生成文件的命令前，读取[工作区布局](layout.md)，按目录职责和文件组织要求确定归属与输出位置；收尾按其中的生成与清理要求处理。
- 操作失败、超时、取消或需要重试时，先按[操作失败与重试](operations.md)核对实际状态，再决定后续工作。

## 按任务读取

| 任务 | 主题或下一级入口 |
|---|---|
| 启动项目、准备目录、组织文件和产物 | [工作区布局](layout.md) |
| 构建项目或准备发布构建 | [项目构建](build.md)、[工作区布局](layout.md) |
| 阅读、检索、分析或比对外部项目源码 | 先读[参考项目源码](references.md)，本地位置遵循[工作区布局](layout.md) |
| 编写或运行本机辅助工具 | [本机开发工具](tools.md)、[工作区布局](layout.md) |
| 维护本机开发说明、资料位置、事项进展与必要验证结果 | [工作区开发文档](docs.md) |
| 建立、领取、交接或验收工作区事项 | [事项入口](tasks/AGENTS.md) |
| 开展测试、清理测试临时文件或维护约束 | [测试入口](testing/AGENTS.md) |
| 派发、复用与验收子智能体任务 | [子智能体协作](collaboration.md) |

维护本目录规则时，遵循[规则维护入口](../AGENTS.md#维护规则)，再读取受影响主题。
