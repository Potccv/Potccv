# 通用约定

本目录按独立职责组织通用约定，各领域目录并列，任务入口直接指向所需规范。本目录的维护规范见 [AGENTS.md](AGENTS.md)。

| 入口 | 内容 |
|---|---|
| [工作区布局](workspace/AGENTS.md) | 目录职责、文件组织、生成与清理，以及参考源码的本地获取和阅读要求 |
| [编程规范](coding/AGENTS.md) | 编程基本原则、本机工具的独立性与依赖、修改范围和子智能体协作 |
| [测试与验证](testing/AGENTS.md) | 测试输入隔离、验证协作、测试批次的命名与清理 |
| [demo 交付](demo/AGENTS.md) | demo 范围、产物位置与运行说明 |
| [文档与资料](docs/AGENTS.md) | 文档职责、资料归档、逐事项交接、文末时间记录与交付说明 |
| [版本与提交](git/AGENTS.md) | 版本与授权约定、SSH 签名配置、提交核验和推送方式 |
