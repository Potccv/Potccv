# 通用约定

本目录按独立职责组织通用约定，各领域目录并列，任务入口直接指向所需规范。本目录的维护规范见 [AGENTS.md](AGENTS.md)。

| 入口 | 内容 |
|---|---|
| [工作区布局](workspace/AGENTS.md) | 发布内容与开发测试资料的存放位置 |
| [编程与设计](coding/AGENTS.md) | 需求验收、架构边界、命名、类型、错误、并发、界面与重构 |
| [接口与集成](interfaces/AGENTS.md) | 接口契约、兼容性、错误、超时重试、幂等、分页与消息 |
| [数据与存储](data/AGENTS.md) | 数据模型、表示、事务、查询、迁移、缓存与文件 |
| [安全与隐私](security/AGENTS.md) | 信任边界、输入校验、身份授权、密钥、隐私与安全验证 |
| [依赖与构建](dependencies/AGENTS.md) | 依赖选择、版本环境、升级、可复现构建与供应链 |
| [测试与验证](testing/AGENTS.md) | 按风险选择检查、用例设计、失败处理、结果记录与临时目录 |
| [运行与发布](operations/AGENTS.md) | 配置、日志指标、资源边界、性能、发布、回退与故障恢复 |
| [demo 交付](demo/AGENTS.md) | demo 范围、产物位置与运行说明 |
| [文档与资料](docs/AGENTS.md) | 文档职责、维护方法、资料归档与状态记录 |
| [环境连接与消息](communication/AGENTS.md) | 环境连接方式、消息图片与所需个人参数 |
| [版本与提交](git/AGENTS.md) | 变更组织、代码评审、交付说明、版本授权、签名与推送 |

环境配置相关内容见[个人配置导读](../profile/README.md)。
