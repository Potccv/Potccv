# 通用约定

本目录按源码仓库与工作区两个作用范围组织约束。执行入口见[本目录 AGENTS.md](AGENTS.md)，由源码仓库或工作区的下级入口选择具体主题；共用的范围判定和维护要求见下表。

| 入口 | 内容 |
|---|---|
| [约束范围](scope.md) | 任务授权、规则冲突、文档归属与交付说明 |
| [规则文档维护](maintenance.md) | 规则归属、写作、迁移与核对要求 |
| [源码仓库规则](repo/README.md) | 编程、正式文档、测试源码、Git 版本与提交、demo 交付 |
| [工作区规则](workspace/README.md) | 目录布局、本机资料、事项、工具、验证运行、任务协作与参考源码 |
